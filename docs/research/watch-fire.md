# Watch Fire: useful patterns and original-source routes

Checked 14 November 2026. **Watch Fire supplies useful incident-context and source-health patterns; its breadth does not establish validated spread or impact prediction.** This is bounded public-interface research, not a licensed application starter or a production feed dependency. ApexFire's authoritative scope remains [PROJECT.md](../../PROJECT.md). Parent owns browser observations and original-provider acquisition; no competitor dataset or application code was adopted.

## What is actually evidenced

The [source page](https://www.watch-fire.com/en/faq/sources) lists satellite, agency, weather, biodiversity, settlement, aircraft and news providers. Listing alone proves attribution intent, not a working integration. Its blanket description as open data needs qualification: Protected Planet and IUCN impose restrictions; GBIF records have different licenses; publisher photographs have separate rights.

Public module inspection found a React/MapLibre client using same-origin services. [Evidence manifest](watch-fire/public-bundle-observations.json) records asset URLs, hashes and declared route strings; proprietary bundles remain temporary and are not redistributed. Code paths expose weather batching, official incidents/perimeters, risk/hazard panels, follow/location alerts, moderated media/reports and printable/shareable details. Reading code paths does not verify that notifications arrive or every upstream provider works.

A public risk-summary GET returned timestamped cells. One parameterized Balkan risk-detail GET returned a source list naming FIRMS, MET Norway, Protected Planet, GBIF, Mapzen/OpenTopoData, WorldCover and NASA POWER, with populated spread/environment/nature fields. This **verifies response structure and declared provenance**, not the upstream requests, methodology or an actual incident: the detail query used illustrative numeric fire inputs. Sanitized [schema observations](watch-fire/public-response-observations.json) retain no species coordinates or competitor feed. The model formula, calibration and predictive error are unknown.

A concrete source-list omission candidate is **Overture Maps**: public client code labels `estimatedLocalImpact.method=overture-exact` as Overture and `ghsl-raster` as GHSL; Overture is absent from the inspected FAQ. This is a declared optional branch, not proof it executed for a particular fire. Mapzen is another upstream provenance detail hidden by listing only the OpenTopoData service. Verify original product/release licenses; aggregator/service licenses cannot replace underlying-data rights.

## Three highest-value additions

1. **Dated GIBS true-color imagery for cases.** Low integration cost, directly supports observed evidence. Test a cloud-free local date, acquisition/source identity and overlay alignment; use a dated layer rather than an always-current background.
2. **CAMS air-quality context through the existing Open-Meteo access pattern.** A bounded PM₂.₅/AQI sample adds a useful environmental dimension. Label modeled concentration and resolution; it does not identify a particular wildfire's smoke contribution.
3. **Small GHSL/settlement context extract.** Prepare a local built-up/population reference and attributed places. Initially show nearby context; compute exposure only against a defensible observed/scenario boundary and explicit epoch. No evacuation time or people-at-risk claim from proximity alone.

These are additions after the historical/case/model core, not reasons to replace it or postpone the first build. Official incident enrichment is the next candidate once North Macedonia coverage is demonstrated.

## Original-provider acquisition and access

**GIBS — download/test now, no key.** [NASA API documentation](https://nasa-gibs.github.io/gibs-api-docs/access-basics/) documents public WMTS/WMS/XYZ services, time dimensions and tile grids. Start with [EPSG:3857 capabilities](https://gibs.earthdata.nasa.gov/wmts/epsg3857/best/1.0.0/WMTSCapabilities.xml); select the actual layer/grid/format before constructing `/wmts/epsg3857/best/{layer}/default/{YYYY-MM-DD}/{matrix}/{z}/{y}/{x}.jpg`. Candidate: `VIIRS_SNPP_CorrectedReflectance_TrueColor`. North Macedonia lies within global coverage; cloud, smoke, acquisition gaps and pending same-day processing can leave blank tiles. Credit NASA/GIBS and the selected product; inspect layer-specific metadata/third-party terms. Browse imagery is not quantitative burned-area truth or the original scientific reflectance file. Keep dates explicit; special `current` time is unsupported.

**CAMS/Open-Meteo — sample now, no free-tier key.** [Air-quality docs](https://open-meteo.com/en/docs/air-quality-api) provide a direct [Skopje test request](https://air-quality-api.open-meteo.com/v1/air-quality?latitude=41.9981&longitude=21.4254&hourly=pm2_5,pm10,european_aqi&domains=cams_europe&forecast_days=1&timezone=GMT). Explicit `cams_europe` prevents silently switching domains. The European product is about 11 km, hourly, refreshed daily; MK's grid response still needs numeric validation. Credit CAMS ENSEMBLE and Open-Meteo under the documented attribution conditions. [Free hosted terms](https://open-meteo.com/en/terms) permit noncommercial use below 10,000 calls/day, 5,000/hour and 600/minute; data license and hosted-service eligibility differ. No API purchase is needed for this prototype. Direct [Copernicus ADS](https://ads.atmosphere.copernicus.eu/) bulk acquisition is a later route requiring account/token and dataset terms; it adds no necessary first-build benefit.

**MET Norway — optional fallback/comparison, no key.** [Locationforecast compact](https://api.met.no/weatherapi/locationforecast/2.0/compact?lat=41.9981&lon=21.4254) supplies point forecasts. [Current FAQ](https://docs.api.met.no/doc/locationforecast/FAQ.html) says non-Nordic forecasts use ECMWF HRES interpolation, not Nordic observation postprocessing; MK accuracy superiority is unproved. It updates outside the Nordic area every six hours; wait at least three hours between identical queries, never schedule on the hour, and honor longer cache headers. [Terms](https://docs.api.met.no/doc/TermsOfService) require legitimate application identification, caching and human acceptance; [HOWTO](https://docs.api.met.no/doc/locationforecast/HowTO) recommends a cache/proxy rather than production browser requests. CC BY attribution applies. Keep Open-Meteo as primary; do not reuse its hourly poll cadence for MET. Global historical gridded files are not freely distributed through MET's Nordic THREDDS.

**GHSL — bounded extract next, no key.** [Official wizard](https://human-settlement.emergency.copernicus.eu/downloadWizard.php) and [direct downloads](https://human-settlement.emergency.copernicus.eu/download.php?ds=pop) offer global GeoTIFF tiles; MK is included. Select release, epoch, resolution and CRS explicitly, then crop locally. [GHS-POP R2023A](https://human-settlement.emergency.copernicus.eu/ghs_pop2023.php) expresses residents per cell; 2025/2030 are projections, not a new census. Built-up surface measures area, not occupants. [Reuse conditions](https://human-settlement.emergency.copernicus.eu/GHSLhowToCite.php) require acknowledgment. Avoid downloading the global 100 m raster; select intersecting tiles and preserve population totals during reprojection. A tile binary has not been verified in this report.

**EONET/GDACS/EMS — small coverage tests, no new key first.** [EONET v3](https://eonet.gsfc.nasa.gov/docs/v3) supports [MK-region wildfire lookup](https://eonet.gsfc.nasa.gov/api/v3/events?category=wildfires&status=all&start=2024-07-01&end=2024-09-30&bbox=20.4,42.4,23.1,40.8&limit=10). Its unusual bbox order is west,north,east,south. Curated geometry/time/source references are useful incident links, not a complete detection archive; midnight may indicate unknown precise time, and closed time is approximate. [GDACS API guide](https://www.gdacs.org/Documents/2025/GDACS_API_quickstart_v2.pdf) documents public GeoJSON search, attribution and 100-record pagination; use wildfire event type only after Swagger/sample confirms it, then locally filter geography. Preserve contributing-source terms. [CEMS activation downloads](https://mapping.emergency.copernicus.eu/about/rapid-mapping-manual/product-overview/how-is-a-product-delivered/viewing-and-downloading-a-product/) supply activation-specific mapping; no activation means no product, not no fire. MK-specific incident coverage remains to be tested. ReliefWeb is deferred: [current API docs](https://apidoc.reliefweb.int/) require a **pre-approved appname**, and report content retains source rights. Do not invent an appname or assume an API key alone solves this.

**Protected Planet/GBIF/IUCN — defer product integration.** [Protected Planet v4](https://api.protectedplanet.net/documentation) needs a bearer token; [API policy](https://api.protectedplanet.net/) excludes commercial use broadly, and old v3 is obsolete. Use official country downloads only after accepting current terms; verify MK boundaries and redistribution permissions. [GBIF search](https://techdocs.gbif.org/en/openapi/v1/occurrence) allows small anonymous GETs such as `https://api.gbif.org/v1/occurrence/search?country=MK&hasCoordinate=true&limit=5`; authenticated asynchronous downloads provide reproducible DOI datasets. Preserve each record's CC0/CC BY/CC BY-NC license. Occurrence age, uncertainty, sampling bias and sensitive-location generalization defeat claims of current local populations or casualties. [IUCN API](https://api.iucnredlist.org/) restricts commercial use and some visualization uses; its token and caching conditions require separate review. These layers are not uniformly open or deadline-critical.
